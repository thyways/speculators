## Objective

Build and verify an end-to-end DFlash training path for `Infinity-Parser2-2B-2604` using responses regenerated by that exact model. Use a deterministic nested sample: 100 records for smoke validation, the first 800,000 eligible ranks for the pilot, and the first 1,500,000 eligible ranks for final large-scale validation.

## H1 — regeneration and preparation

Prediction: the pipeline will preserve prompts, turn order, metadata, and image assignment while replacing every assistant response with target-model output. After strict media/token-length filtering and ranked reserve backfill, the prepared Arrow dataset will contain exactly the requested stage count and retain the multimodal `messages`, `input_ids`, `loss_mask`, `seq_len`, `source_line_index`, and `candidate_rank` columns.

Acceptance criteria:

1. Teacher model path and served model ID both equal `/home/ma-user/work/data_mllm/publish_models/Infinity-Parser2-2B-2604`.
2. Sampling is deterministic at seed 42; smoke is nested in 800k, and 800k is nested in 1.5M.
3. Old assistant text never appears in generation requests; multi-turn assistant replies are regenerated sequentially.
4. Final validation reports exact counts, complete JSONL lines, valid media paths, stable hashes, and no unresolved placeholders.
5. Prepared data is tokenized by the same target processor and vocabulary mappings are internally consistent.

## H2 — requested training recipe

Prediction: the five-layer Qwen3 DFlash draft can train with bidirectional sliding-window attention, AdamW, and cosine decay while preserving Parser2 MRoPE and online multimodal hidden-state alignment.

Locked configuration:

- speculator: DFlash, block size 8, five draft layers
- attention: `simple_flex_attention`, sliding window 2048, `sliding_window_non_causal=true`
- optimizer: AdamW, initial learning rate `1e-4`, weight decay `0.01`
- schedule: cosine, 4% warmup for pilot/full; one warmup step in the 10-step smoke run
- target hidden-state indices: 2, 12, 21, plus verifier final layer 24
- training: BF16 hidden states, strict failure on generation/token mismatch, online file backend

Smoke acceptance criteria:

1. A real multimodal Arrow item round-trips through vLLM with exact prepared token IDs.
2. Six-rank DDP completes 10 optimizer steps with no NaN/Inf, OOM, hidden-state failure, or token mismatch.
3. Training emits finite loss metrics and at least one valid `model.safetensors` checkpoint.
4. Resolved config proves AdamW, cosine decay, and bidirectional attention were active.

## Scale-up decision

Proceed from smoke to 800k only after all smoke criteria pass. Proceed from 800k to the nested 1.5M final validation only after data and training stability are confirmed. Final acceleration claims require an autoregressive baseline, DFlash throughput/latency, acceptance length, and output-equivalence checks on the same held-out prompts.

## Pre-generation amendment: one 1.5M corpus, nested 800k training view

At the user's direction, generate and preprocess the full deterministic 1.5M stage once instead of publishing a separately tokenized 800k corpus first. The pilot training run will consume exactly the first 800,000 preprocessing-eligible Arrow rows in ascending `candidate_rank` order, then apply its 99/1 train/validation split within that prefix. The full run will consume all 1,500,000 rows.

This amendment preserves the original nested-sample claim while avoiding a second merge, target-tokenization pass, and vocabulary build. The 800k and 1.5M runs intentionally share the vocabulary mapping computed from the complete 1.5M corpus; that shared mapping is part of the amended protocol and must be disclosed in analysis. No rows after the 800,000-row boundary may contribute gradients or validation hidden-state requests during the pilot run.

Additional acceptance criteria:

1. The full prepared Arrow dataset contains exactly 1,500,000 rows sorted by strictly increasing `candidate_rank`.
2. The pilot loader applies its 800,000-row limit before the train/validation split, yielding exactly 792,000 training and 8,000 validation records at ratio 0.99.
3. A regression test proves that both pilot splits are contained in the first 800,000 rows and that row 800,000 or later is never accessed.
4. Regeneration remains deterministic with `temperature=0`, `top_p=1`, seed 42, thinking disabled, and the exact `Infinity-Parser2-2B-2604` teacher.
